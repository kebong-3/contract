# 2026-10-23 실무 활용성 재평가

## 판단

기존 버전은 보기 좋은 시연용 구매 검토 도구에 가깝다. 출처와 비교 제외 이유를 보여주는 방향은 좋지만, 실제 견적의 총액·누락 비용·유효기한과 선택 이유를 이어 주지 못했다. 자료 건수와 연결 API 수만 늘려서는 이 약점을 해결하지 못한다. 수상 점수나 98점 달성을 예측할 검증 근거는 없다.

이번 개선은 **참고자료 확인 → 받은 견적의 동일 조건 비교 → 담당자 대안·선택 이유 → 검토서**로 연결한다. 기관의 계약·회계 시스템을 대체하는 수준은 아니며, 실제 공무원의 사용성 검증도 아직 수행하지 않았다.

## API는 하나의 상세기능만 추가

법령 자동판정·뉴스·날씨·통계·지도 API는 현재 물품 견적 비교를 끝내는 데 직접 필요하지 않아 추가하지 않았다.

## 해결한 불편

1. 본체가 싸도 부대비용이 큰 견적을 구분: 배송·설치·유지관리·부가세를 명시적으로 합산한다. 미확인은 0원으로 처리하지 않는다. 별도 부가세를 임의로 10% 계산하지 않는다.
2. 수량·단위가 다른 견적, 유효기간이 지난 견적, 필수 조건을 확인하지 않은 견적은 선택 가능한 대안에서 제외한다. 총액 표시와 조건 충족 여부를 구분한다.
3. 담당자가 조건이 확인된 대안과 10자 이상의 이유를 기록한다. 최저가 자동 추천·낙찰·결재로 표현하지 않는다.
4. 공고 계획단가·낙찰 총액·쇼핑몰 계약단가를 구분한다. 계획가격과 미확인 자료로 중앙값을 만들지 않는다. 비교 가능 사례가 3건 미만이면 대표 시세로 해석하지 않도록 표시한다.
5. 조회 기간·페이지·반환 건수·전체 건수·조회 시각을 표시하고 검토서에 남긴다. 재조회가 원문 확인 후 수정한 값이나 제외 기록을 덮어쓰지 않는다.
6. CSV 비교표와 JSON 백업에 새 작업 내용을 담는다. CSV의 수식 시작 문자와 따옴표를 처리한다.

## 실제 확인 범위와 남은 일

- 배포 주소 `https://contract-ten-kappa.vercel.app/`의 화면과 연결 설정을 확인했다. 확인 당시 Groq와 Google 키는 설정됨, 공공데이터 키는 설정 필요로 표시됐다. 인증키 내용은 열람하지 않았다. 다른 환경이나 프로젝트에 등록된 것인지는 확인하지 않았다.
- 공공데이터 3종과 새 상세기능은 공식 문서 및 가상 응답으로 검증했다. 실제 키가 적용된 배포에서의 정상 조회·자료 연결률은 아직 입증하지 못했다.
- 두 AI 모델의 실제 성공 응답·계정별 할당량은 이번 작업에서 검증하지 않았다.
- 계산·자료 분류·입력 검증·중복 보존·CSV·기존 및 새 백업 테스트를 통과했다. 실제 화면에서 가상 견적의 총액, 누락 항목, 선택 이유 저장과 검토서 반영을 점검했다.
- 대표 숫자 사양 하나는 전체 규격 동등성을 증명하지 못한다. 담당자의 규격서 확인이 필요하다. 임대 총비용은 기간·보증금·해지조건 등의 구조가 별도로 필요하므로 자동 대안 비교를 제한한다.
- 브라우저 로컬 저장이므로 여러 담당자 협업·결재·기관 감사 이력의 무결성은 제공하지 않는다. 파일 자동 판독·나라장터 발주·예정가격 결정도 구현 범위 밖이다.

다음 검증은 API 추가보다 공기청정기·노트북·사무용 의자 각 1건의 실제 공개 사례와 공개/가상 견적으로 진행하는 것이 낫다. 담당자가 완료까지 걸린 시간, 다시 입력한 항목, 놓친 조건을 기록하여 입력 부담이 줄었는지 확인한다. 현재 시간 절감률이나 정확도 수치는 측정하지 않았다.
