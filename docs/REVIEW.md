# 업무 관점 검토 기록

본 프로젝트의 회계·계약·감사 관점 검토는 AI가 역할을 나누어 수행한 **모의 전문가 검토**입니다. 실제 베테랑 공무원 3명, 사용자 또는 기관이 참여·검증했다는 의미가 아닙니다.

## 회계 담당자 관점

- 예산 상한을 권장 가격으로 사용하지 않습니다.
- 참고 소요액은 비교 가능 사례의 중앙값 × 요청 수량으로 산출합니다. 실제 예정가격·기초금액이 아닙니다.
- 사례가 없으면 금액을 0원으로 표시하지 않고 미산출로 남깁니다.
- 부가세 기준이 다르거나 불명확하면 자동 단가 비교에서 제외합니다.

## 계약 담당자 관점

- 구매와 임대, 복합 구성과 단품을 구분합니다.
- 설치·유지관리 등 필수 조건을 충족하지 않는 사례는 제외합니다.
- 낙찰 총액을 근거 없이 단품 가격으로 환산하지 않습니다.
- 본 앱은 계약방법·수의계약 가능 여부·업체 선정의 적법성을 판정하지 않습니다.

## 사후 검토 관점

- 데모는 가상기관과 합성 가격으로 구성하며 원문 링크를 꾸미지 않습니다.
- 실제 조회 자료에는 출처·조회 시각·확인 상태를 보존해야 합니다.
- 담당자가 보완할 사항을 명시하고 최종 검토를 거칩니다.

## 제출 전 실제 사용자 검증

실제 담당자에게 공개·가상 사례로 사용성 시험을 요청하고, 과업 완료시간·누락·수정량을 측정해야 합니다. 아직 수행하지 않은 효과 측정이나 전문가 참여를 성과로 표기하지 않습니다.
