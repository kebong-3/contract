# 조달근거

공공기관 담당자의 물품 구매 검토를 돕는 Next.js 웹앱입니다. 요청 조건을 입력하고 사례의 비교 가능성을 확인한 뒤 검토서 초안을 준비합니다. 로컬 AI나 GPU는 필요하지 않습니다.

## 시작

```sh
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 합성 데이터 체험에는 API 키가 필요하지 않습니다. 기관명·가격·날짜는 모두 가상이며 실제 계약 근거로 사용할 수 없습니다.

## Vercel 배포

1. 이 저장소를 Vercel에서 Import합니다.
2. Framework Preset은 Next.js, Root Directory는 저장소 최상위로 설정합니다.
3. 필요한 환경변수를 프로젝트 Settings → Environment Variables에 입력합니다.
4. Deploy 후 연결 상태와 실제 계정 한도를 확인합니다. 환경변수를 변경하면 다시 배포합니다.

| 환경변수           | 용도                                                              |
| ------------------ | ----------------------------------------------------------------- |
| `GROQ_API_KEY`     | GPT-OSS용 Groq 비밀키                                             |
| `GROQ_MODEL`       | 모델 식별자. 기본 `openai/gpt-oss-120b`                           |
| `GEMINI_API_KEY`   | Google 모델 API 비밀키                                            |
| `GEMMA_MODEL`      | 계정에서 사용할 수 있는 Gemma 모델 식별자. 기본값은 코드에서 확인 |
| `APP_ACCESS_TOKEN` | AI 요청 접근 암호. 공개 배포에서 사용 권장                        |

키 이름에 `NEXT_PUBLIC_`을 붙이지 마세요. API 키는 Vercel 서버 환경변수로만 관리합니다. 무료 이용 가능 여부·할당량·과금 조건은 각 제공자의 실제 계정 설정을 확인하세요. 키가 없으면 AI 요청에 설정 안내가 표시되며, AI가 실행된 것처럼 표시하지 않습니다.

공공데이터는 API 3종의 활용승인 후 `DATA_GO_KR_SERVICE_KEY`만 등록하면 공식 조회주소가 자동 적용됩니다. 주소 세 개를 따로 입력할 필요가 없습니다. 이전에 `PROCUREMENT_*_URL`에 임시 값이나 인증키를 넣었다면 세 URL 변수만 삭제하고 재배포하세요. `.env.example`과 [배포 안내](docs/VERCEL.md)에 자세히 설명했습니다. 실제 응답을 받지 못했을 때 데모 사례로 몰래 대체하지 않습니다. 실시간 자료에서도 필수 사양·수량·부가세 등 확인이 부족하면 비교가 제한됩니다.

## 이번 개선: 참고자료에서 받은 견적 검토까지

- 받은 견적 최대 20건: 본체 × 수량 + 추가 배송·설치·유지관리비 + 명시된 부가세액을 비교합니다. 모르는 비용은 미산출로 남깁니다.
- 수량·단위·유효기한·필수 조건·부가세 기준을 확인한 견적에서 담당자가 검토 대안과 선택 이유를 기록합니다. 자동 낙찰·결재가 아닙니다.
- 공고 계획단가, 낙찰 총액, 쇼핑몰 계약단가를 구분합니다. 원자료를 확인하기 전 실시간 자료는 중앙값에 들어가지 않습니다.
- 공고 상세에서 구매대상 물품 구성·규격·수량을 추가 조회합니다. 이미 승인한 입찰공고정보서비스와 같은 인증키를 사용합니다.
- 조회 기간·페이지·반환 건수·조회 시각을 기록하고 다음 페이지를 수동으로 추가합니다. 재조회가 담당자 수정값을 덮어쓰지 않습니다.
- 비교표 CSV와 작업 백업에 견적·선택 이유·조회 범위가 포함됩니다. 기존 백업도 읽을 수 있습니다.

[냉정한 평가와 API 선정 근거](docs/ASSESSMENT.md)를 함께 보세요.

## 검토 원칙

- 구매·임대 방식, 필수 사양, 설치·유지관리 조건을 확인합니다.
- 복합 구성이나 세트를 임의의 단품 단가로 환산하지 않습니다.
- 조건부·제외 사례는 금액 중앙값에 포함하지 않습니다.
- 참고 소요액 = 비교 가능 사례 단가 중앙값 × 요청 수량입니다.
- 수량할인·시점·운송·설치 범위 차이까지 가격 동등성이 입증되는 것은 아닙니다.
- 계산값은 예정가격·적정가격·발주 승인 또는 법적 판단이 아닙니다.

## 자료 보관과 공유 컴퓨터

입력 내용과 검토 초안에는 공개자료 또는 가상자료를 사용하세요. 화면에서 초안을 보관하면 해당 브라우저의 저장공간을 사용하며, 기관 공용 문서함이나 서버 백업이 아닙니다. 다른 기기와 자동으로 동기화되지 않습니다. 공유 컴퓨터에서는 사용 후 저장된 초안을 삭제하고, 다운로드한 파일과 출력물을 직접 관리하세요.

실제 AI 기능을 사용하면 전송한 요청·근거가 선택한 외부 AI 제공자에게 전달됩니다. 주민등록번호, 계좌번호, 연락처, 비공개 견적·계약자료를 입력하지 마세요. 제공자의 데이터 처리조건과 기관 정책을 확인한 뒤 사용해야 합니다. 접속 암호를 설정해도 앱 자체가 기관용 권한·감사 관리 시스템이 되는 것은 아닙니다.

## 검증

```sh
npm run build
npm test
```

Node.js의 타입 제거 실행 기능을 지원하는 버전을 사용합니다. 도메인 테스트는 임대·복합 구매 제외, 미확인 조건 처리, 중복 방지, 중앙값 계산, 사례 없음과 잘못된 수량 처리를 검증합니다.

## 구현 범위와 한계

공기청정기·노트북·사무용 의자 합성 사례를 제공합니다. 대표 숫자 사양 하나만으로 물품의 모든 사양이 일치하는지 판단할 수 없으며, 실제 사용 전 규격서·가격 구성·계약 기간을 담당자가 확인해야 합니다. 공개 API의 자료 제공 범위, 응답 속도, 식별자 연결률은 다를 수 있습니다. 첨부문서 전체 자동 판독과 법령 적법성 판단은 보장하지 않습니다. 두 AI 모델의 실제 정상 작동은 해당 키로 시험해야 입증됩니다.

프로젝트의 회계·계약·사후 검토 역할은 **AI 모의 전문가 검토**입니다. 실제 베테랑 공무원 3명 또는 실제 사용자 참여를 주장하지 않습니다. [검토 기록](docs/REVIEW.md)을 참고하세요. 실제 업무시간 절감·정확도·사용성 효과는 별도 사용자 시험이 필요합니다.
